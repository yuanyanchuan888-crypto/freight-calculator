# 发布检查清单

每次发布前按本清单逐项复核，不将历史通过结果视为本次版本的自动通过。

## 源码与权属

- [ ] 项目权利人核对版权声明主体、年份及其授权 MIT 许可证的权利。
- [ ] 检查待提交文件、Git 历史、构建配置、测试数据及输出中是否包含密钥、个人信息、客户/供应商资料或内部价格。
- [ ] 核对运行依赖、构建依赖、许可证和已知安全公告。
- [ ] 对随附 EXE 的 CPython、Tcl/Tk、Microsoft VC Runtime 及其他打包组件核对适用通知，并随二进制提供所需声明。

## 功能和构建

- [ ] 从干净源码环境按 README 独立安装并运行。
- [ ] 运行完整自动化测试、代码编译检查和依赖完整性检查。
- [ ] 在目标 Windows 环境启动便携 EXE，验证 UI、计算、Excel 模板、导入、导出与回读。
- [ ] 验证构建脚本能从声明依赖生成 EXE；记录 Python、PyInstaller 和操作系统版本。
- [ ] 在未安装 Python 的普通 Windows 设备测试 EXE，并记录 SmartScreen、安全软件、DPI 和兼容性提示。
- [ ] 生成 SHA-256 校验值；核实文件哈希和最终 Release 附件一致。

## GitHub 发布

- [ ] 核对仓库名称、Owner、可见性、描述、Topics、Issue 模板和默认分支。
- [ ] 检查精确提交树和 CI 结果；源码中不提交构建目录、虚拟环境、缓存、测试工作簿或发布截图。
- [ ] 更新 `CHANGELOG.md` 和 Release 正文，列明新功能、限制、安装方法和校验值。
- [ ] 经项目权利人确认后，提交源码、推送标签、创建 Release 并上传批准的附件。
