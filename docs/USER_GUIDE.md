# 用户指南

## 启动

Windows 用户可双击 `dist\FreightCalculator.exe`（构建后提供），或按项目 README 中的 Python 命令启动。程序不需要网络连接。

## 录入货物

1. 在“计费规则”中选择体积重除数、计费口径和进位单位。默认参数仅用于计算示例。
2. 选择新行默认尺寸和重量单位。该设置只影响后续新增的货物行。
3. 点击“新增货物”，填写货物名称、相同规格的包装件数、单件外箱尺寸和单件实际重量。
4. 单位可逐行选择。修改货物行时，双击该行或选择后点击“编辑选中”。
5. 表格与汇总区域会更新体积、实际重量、体积重，以及两种示例计费口径的结果。

快捷键：`Insert` 新增货物，`Delete` 删除选中货物，`Ctrl+Enter` 重新计算。

## 选择计费规则

- “逐件计算”先按每件比较实际重量与体积重并进位，再乘件数。不同包装规格应分开录入。
- “整票汇总”先把整票实际重量和体积重分别合计，再比较并进位。
- 进位增量为 0.5 kg 时，2.51 kg 会向上计为 3.0 kg；正好为 2.5 kg 时仍为 2.5 kg。
- “自定义”除数和进位必须是大于 0 的有限数值。

不同承运渠道可能采用最低计费、尺寸限制、分泡/计泡、不同进位方式或附加费用。请按对应渠道针对该票货物的书面规则核实，不能仅凭本工具结果认定承运商账单。

## Excel 导入与导出

点击“导出模板”后，模板含“货物明细”“计算参数”“填写说明”工作表。黄色单元格为输入区域，表格提供基本数据验证。填写完成后保存为 `.xlsx`，再点击“导入 Excel”。

导入时如果文件包含计算参数，会询问是否同时使用这些设置。确认单位及参数后再使用计算结果。模板最多填写 5,000 行。空白模板不会带入示例货物。

点击“导出 Excel”会生成包含汇总、货物明细和计算参数的工作簿。结果为导出时的静态核算快照。导入时公式不会执行，建议把需导入的公式结果复制并粘贴为普通数值后再导入。

## 常见问题

**导入提示缺少工作表或列**
使用本工具模板，或确认“货物明细”工作表及必需列名完整。列顺序可以调整。

**重量结果与货代账单不同**
检查承运渠道使用的除数、计费方式、进位、最低计费、尺寸限制、分泡/计泡、清关与派送范围及附加费用。此工具不内置承运商规则。

**启动时提示缺少 Excel 依赖**
Python 方式运行时，在项目目录执行 `python -m pip install -r requirements.txt`。便携 EXE 正常情况下不需要单独安装 Python 或 `openpyxl`。

**数据是否上传**
计算器不联网、不自动上传。导入和导出仅在用户选择文件时访问该文件。
