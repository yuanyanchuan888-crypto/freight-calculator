# International Freight Calculator v0.2.0

First release of the local desktop calculator.

## Highlights

- Chinese desktop interface for multiple cargo lines and multiple pieces per line.
- Converts cm/in and kg/lb inputs to metric values for calculations.
- Supports volumetric divisors 5000, 6000, or a user-defined divisor.
- Shows per-piece and whole-shipment chargeable-weight approaches side by side, with configurable upward rounding.
- Imports `.xlsx` templates and exports a static calculation workbook with summary, cargo detail, and calculation settings.
- Performs calculation and file processing locally; no automatic network upload or carrier-rate lookup.

## Calculation note

Divisors, rounding increments, and chargeable-weight methods are configurable examples, not universal carrier rules. Confirm the applicable written rules, minimum charges, dimensional limits, and service scope with the selected carrier before relying on a result.

## Windows portable build

The release asset is planned to be `FreightCalculator.exe`. It was tested on the project build machine, including an isolated launch without Python or developer-tool runtime paths. It is unsigned and has not yet been verified on a second Windows computer; SmartScreen or security software may show a warning. Do not treat this as a signed installer.

Redistribute the executable with applicable notices for bundled CPython, Tcl/Tk, Microsoft VC Runtime, and other components after reviewing their terms.

## Source installation

Requires Python 3.11 or newer with Tkinter. From the repository root:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m freight_calculator
```
