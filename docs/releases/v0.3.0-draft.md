# International Freight Calculator v0.3.0 (Draft)

> **Not released.** This source-only release note is for review. Do not publish or attach a Windows executable until the maintainer approves the final release.

## Highlights

- Reworked the Chinese desktop layout to adapt to window width and height, with a smaller supported window, responsive calculation settings, summary cards, and table scrolling.
- Made the divisor, billing basis, and rounding example visible in the interface so results are easier to interpret.
- Preserved the v0.2.0 blank Excel input-sheet schema and added a separate synthetic demonstration sheet, readable number formats, and summary checks.
- Expanded UI and Excel regression coverage and refreshed the Chinese user and testing guides.

## Calculation and Excel behavior

The calculator continues to show per-piece and whole-shipment calculation examples. Divisors and rounding are configurable examples, not universal carrier rules; confirm the selected service's written chargeable-weight and rounding terms before use. Excel import accepts `.xlsx` only, does not execute formulas or macros, and enforces documented file and row limits.

## Verification on the current Windows machine

- 22 automated tests passed on the current Python 3.12.14 environment.
- `pip check` passed; `pip-audit` reported no known vulnerabilities for the declared runtime and build requirements.
- The v0.3.0 portable executable was launched from an isolated clean-run folder on the current machine without using Codex's Python runtime. Its hash is recorded in the local test log; the EXE is intentionally not included in this source-only release.
- The window was visually checked at the configured minimum size and common 1280×720 and 1366×768 sizes. Keyboard Insert/Escape was smoke-tested.
- A generated v0.2.0-schema workbook imported successfully with its cargo and calculation settings preserved.

## Known verification limits

- Only the current 1920×1080, 96-DPI (100%) display was available. 125%/150% high-DPI behavior has not been visually verified.
- The executable has not been tested on a separate clean Windows computer or virtual machine. It is unsigned, so SmartScreen or endpoint security may show a warning.
- The 1280×720 and minimum-size layouts keep controls and summary visible; wide tables use horizontal scrolling by design.
- The current machine's `dist/FreightCalculator.exe` is a v0.2.0 build. Do not use it as a v0.3.0 release asset; the identified v0.3.0 build remains under ignored `artifacts/` and is not part of the public file list.
