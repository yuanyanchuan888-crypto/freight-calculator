# 自动化测试说明

## 执行

在 Windows PowerShell 的项目目录中运行：

```powershell
py -3.12 -m unittest discover -s tests -v
```

如使用其他 Python 3.11+ 安装，将 `py -3.12` 换成相应的 Python 命令。Excel 测试需要安装 `requirements.txt` 中的依赖。Tkinter UI smoke test 在没有可用图形显示环境时会跳过；跳过不代表完成了可视化验收。

## 覆盖范围

- 多行、多件货物的体积、实际重量和体积重合计。
- cm/in、kg/lb 换算，除数 5000、6000、自定义值。
- 逐件与整票汇总口径差异，精确进位边界和向上进位。
- 空数据、负值、非有限数、非法单位、非法件数和无效计费设置。
- Excel 模板表结构、输入验证、填写说明、空白导入、重排列头和中文单位别名。
- Excel 单元格错误定位、导出汇总与独立计算核对、输入参数往返和公式样式文本安全。
- Tkinter 控件结构、表格结果与自定义参数控件状态（当前 Windows 环境可运行）。

## 可视检查

自动化测试不替代实际 Windows 窗口的视觉检查。验收时打开程序，确认主窗口可见且无裁切；检查参数区、按钮、表头、长数字和六张汇总卡；新增一条测试货物并验证表格、汇总和单位显示；打开新增/编辑对话框，检查输入标签和按钮，再关闭窗口。导出的 `.xlsx` 应在 Excel 或兼容表格程序中打开，核对三张结果表及空白模板的填写引导。

不要将真实客户资料、供应商价格或运单数据用于测试。所有测试使用临时文件和合成货物数据。
